heading(doc,'1. Introducción al desarrollo de software',1)
sub('1.1 Antecedentes','Aprender programación suele comenzar con cursos, videos, documentación y ejercicios separados. El problema no es la falta de información, sino la dificultad para ordenar los contenidos, medir el nivel real y mantener una práctica constante. Muchas plataformas presentan el mismo recorrido para todos, aunque dos personas pueden tener conocimientos y objetivos muy distintos.','Learn2Code parte de esa situación y propone una experiencia donde la ruta no dependa únicamente de una lista fija de temas. El sistema combina información del perfil, resultados del diagnóstico y progreso posterior para orientar la práctica. Esta decisión llevó a diseñar una aplicación con módulos separados, persistencia de datos y servicios capaces de evolucionar sin reconstruir toda la plataforma.')
sub('1.2 Origen de Learn2Code','Learn2Code nació como proyecto académico de EduCode en la Universidad Tecnológica de Tecámac. El desarrollo se planteó para el periodo mayo-noviembre de 2026 con un equipo de dos integrantes y con una primera entrega funcional prevista durante julio. Desde el inicio se buscó resolver un problema concreto: que una persona que quiere aprender programación no tenga que recorrer recursos aislados sin saber por dónde comenzar.','La idea fue evolucionando conforme se validaron necesidades reales. Primero se establecieron arquitectura, base de datos e infraestructura; después se desarrollaron autenticación, perfil y dashboard; más adelante se incorporaron onboarding, diagnóstico, rutas, ejercicios, personalización y gamificación. La evolución por incrementos permitió mantener el proyecto utilizable mientras se corregían decisiones técnicas y visuales.')
sub('1.3 Problemática identificada','La principal necesidad detectada es la desorientación que aparece al comenzar a aprender programación. Una persona puede encontrar cientos de recursos, pero no necesariamente sabe cuál corresponde a su nivel, qué tecnología le conviene, qué tema debe estudiar después o si realmente domina lo anterior.','También existe una separación frecuente entre teoría y práctica. Ver contenido sin escribir código produce una sensación de avance que no siempre se refleja en la capacidad para resolver problemas. Learn2Code busca reducir esa distancia mediante ejercicios, evaluación de intentos y una ruta que conecte diagnóstico, contenidos y práctica.')
sub('1.4 Justificación','Una plataforma de este tipo se justifica porque permite concentrar varias necesidades en una sola experiencia: identificar conocimientos previos, definir objetivos, recomendar una ruta, practicar y conservar el progreso. La personalización no se entiende como mostrar contenido diferente de forma arbitraria, sino como utilizar datos reales del usuario para tomar decisiones dentro del flujo.','El desarrollo web también facilita el acceso desde distintos equipos sin exigir una instalación completa del entorno de programación. El usuario puede trabajar desde el navegador y el backend conserva la lógica sensible, la persistencia y los procesos que no deben ejecutarse directamente en el cliente.')
